# PromptStudio (MVP)

Windows desktop app that generates **text, images, voice (TTS), music and video** through a single
[OpenRouter](https://openrouter.ai) API key. This is the Phase 0–1 MVP from
[`../docs/ai-studio-design.md`](../docs/ai-studio-design.md).

## What works in this MVP

| Area | Status |
|---|---|
| OpenRouter API key stored encrypted (Windows DPAPI via Electron `safeStorage`) | ✅ |
| Model catalog from `GET /models`, filtered per mode (text / image / speech / video), with pricing | ✅ |
| Credit balance in the sidebar (`GET /credits`) | ✅ |
| Prompt composer with mode switch, style presets, aspect ratio, reference images, Ctrl+Enter | ✅ |
| **Enhance prompt** (LLM rewrites your idea for the selected mode) | ✅ |
| Text generation → saved as Markdown | ✅ |
| Image generation (`/chat/completions` with `modalities: ["image","text"]`), batch 1–8 | ✅ |
| Text-to-speech (`/audio/speech`), voice, speed, style instructions, auto-chunking of long scripts | ✅ |
| Music generation (Google Lyria 3 via `/chat/completions` with audio output): genre/mood presets, instrumental or lyrics, mp3/wav | ✅ |
| Video generation (`/videos`, async job queue that survives restarts, background polling) | ✅ (verify field names against OpenRouter docs) |
| Pre-flight cost estimate + actual cost read back from `GET /generation?id=` | ✅ |
| Local library: every file saved to a folder with a `library.json` index, search, delete, reveal | ✅ |
| **Video Editor**: main track (video + image clips), voice, music and caption tracks | ✅ |
| Trim, split at playhead, reorder, drag to move, fade in/out, Ken Burns zoom, mute/volume | ✅ |
| Captions / titles (font, size, colour, box, position), auto-caption from TTS clips | ✅ |
| Live preview player with transport, scrubbing, zoomable timeline, undo/redo, autosave | ✅ |
| Import your own video / audio / images into the library | ✅ |
| MP4 export via FFmpeg (H.264 + AAC) with YouTube / Shorts / square / 4K presets, progress, cancel | ✅ |
| Design canvas, scene builder, pipelines, transitions between clips | ⏳ later phases |

## Run on Windows

Requirements: Node.js 20+ and npm.

```powershell
cd promptstudio
npm install
npm run dev          # launches the app with hot reload
```

Build an installer (`dist/PromptStudio-<version>-x64.exe`) and a portable exe:

```powershell
npm run dist:win
```

Other scripts: `npm run typecheck`, `npm run build`.

## First use

1. Open **Settings** and paste your OpenRouter key (`sk-or-v1-…`), then **Save & test**.
2. Go to **Models** and check which image / speech / video models your account can use.
3. In **Create**, choose a mode, pick a model, write a prompt (or press **Enhance prompt**) and **Generate**.
4. Everything lands in **Library** (default folder: `Documents\PromptStudio`).
5. Open **Video Editor**, add images, videos and voice clips from the Media panel (or **Import** your own files),
   add captions, then **Export MP4**.

### Editor shortcuts

| Key | Action |
|---|---|
| Space | Play / pause |
| S | Split selected clip at playhead |
| Delete | Delete selected clip |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| ← / → (Shift for 1 s) | Nudge playhead |
| Home | Go to start |

Adding a voice clip generated by TTS automatically adds a matching caption with its script.
Music clips default to 30 % volume with a 1 s fade-out. Image clips default to 4 s with Ken Burns zoom.

## Project layout

```
src/main/        Electron main process
  openrouter.ts  OpenRouter adapter (models, credits, chat, image, tts, video, cost)
  generate.ts    text / image / tts / music flows, prompt enhancer, script chunking
  audiostream.ts collects streamed or single-message audio output (pure, unit-testable)
  jobs.ts        persistent async job queue for video
  library.ts     asset + generation index on disk
  settings.ts    settings + encrypted API key
  ffgraph.ts     pure FFmpeg filter-graph builder for timeline export (unit-testable)
  export.ts      runs FFmpeg, streams progress, cancel
  projects.ts    editor project files (projects/*.json in the library folder)
  index.ts       window, IPC handlers, media:// protocol for local files
src/preload/     typed `window.api` bridge (contextIsolation on)
src/renderer/    React UI: Composer, Library, Models, Settings, JobsBar
  components/editor/  EditorView, Preview, Timeline, Inspector, AssetPanel, ExportDialog
  lib/textRender.ts   rasterises captions to PNG (same image used in preview and export)
src/shared/timeline.ts  editor data model, export presets
src/shared/      types and pricing helpers shared by all three
```

## Notes

- Export uses the FFmpeg binary from the `ffmpeg-static` package (downloaded on `npm install`, unpacked
  from the installer). Set `PROMPTSTUDIO_FFMPEG=C:\path\to\ffmpeg.exe` to use your own build.
- Captions are rendered by the UI to transparent PNGs and overlaid by FFmpeg, so the export matches the
  preview exactly and no font configuration is needed.

- The video endpoint is the newest part of OpenRouter's API. `openrouter.ts` reads the job id, status
  and download URL defensively from several possible field names; if a provider returns a different
  shape, adjust `readVideoState()`.
- Music models are detected by name (Lyria, Suno-style, ACE-Step, Stable Audio…) among audio-output
  models in the catalog; they are billed per song or clip, so the pre-flight estimate uses the
  `request` price when OpenRouter lists one and the actual cost is read back after the run.
- Model IDs are never hardcoded for generation: the catalog is fetched at runtime and your last
  choice per mode is remembered.
- Key, settings and job queue live in `%APPDATA%\promptstudio\`.
